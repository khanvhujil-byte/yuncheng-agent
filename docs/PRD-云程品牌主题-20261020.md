# PRD：云程品牌与前端主题

| 项目 | 内容 |
|---|---|
| 日期 | 2026-10-20 |
| 状态 | 用户已授权，设计与实施中 |
| 目标 | 将现有旅行助手的“漫游 ROAM”品牌替换为“云程 YUNCHENG”，形成统一、清爽、易读的云白与天蓝视觉 |

## 问题

现有页面使用草绿、米白和城市插画，品牌与用户要求的“云程”不一致；工作台、表单页、社区及行程组件存在重复硬编码配色。

## 本期范围

1. 使用用户指定的兼容API与`IMAGE_API_KEY`调用生图模型，生成完整工作台设计参考及独立云海山水图片。先完成视觉方案和颜色、字体、间距、按钮规范，再实施。
2. 统一导航、页签标题、图标、页脚和导出文件品牌为“云程 YUNCHENG”。既有入口与交互维持原功能。
3. 用云白背景、天蓝主色、深蓝文字、浅蓝边框更新登录、工作台、传统表单、社区及行程/预算/住宿/编辑组件。失败、警告、未知报价等语义状态保持可辨认。
4. 用生成的云海山水资产替换共享旅行插画；图片独立于文字与按钮，尺寸稳定且加载失败仍能阅读/操作。品牌标记使用清晰的代码原生图标。
5. 适配桌面与手机，支持键盘焦点与减少动态效果偏好。

## 限制与边界

- 继续使用现有Vue、Ant Design和图标库，不迁移框架，不修改规划算法、接口协议、账号或数据库。
- API密钥只在本地进程内读取、通过请求头发送到用户指定服务；不写入源代码、前端包、图片、日志或提交文件。
- 引用对话读取工具当前未提供，不能假定其中存在其他配置；以用户本次明确给出的服务地址与环境变量为准。
- 当前无Browser插件，使用独立Playwright浏览器验证；截图、临时脚本和视觉对照记录保存在项目外。只有最终生产图片进入前端资产目录。

## 成功标准

- 页面与导出不再出现旧品牌，导航与主要操作正常；原有行程局部编辑等流程不受影响。
- 全部主要页面遵循同一配色与字体层级，桌面1440及手机390宽度无横向溢出、遮挡或不可读文字。
- 构建与既有前端测试通过；浏览器检查页面身份、非空、控制台、图片加载和操作反馈。
- 使用`view_image`对照设计参考与最终实装截图，检查文案、布局、文字、颜色、图片与响应式表现，修复明显差异。
- 生图接口验证和产物均真实，不将模型列表可访问等同于生成成功。

## 开发计划

1. 读取现状，确认生图配置；生成设计参考和生产图片。
2. 建立全局主题令牌并实施共享品牌/插画组件，替换重复配色和旧品牌。
3. 运行构建及前端测试，使用独立浏览器检查登录、工作台、表单、社区和已有行程状态，修复视觉与交互问题。

## 设计规范

设计目标：白色主要表面、极浅蓝页面底色、清晰天蓝主操作，深海军蓝标题，蓝灰辅助文字；保持现有信息结构，减少装饰性的英文眉题。使用现有无衬线中文字体和lucide线性图标；按钮、边框、卡片圆角与阴影统一。具体颜色与布局以生成参考的可实施部分登记后执行。


## 已选视觉方案与实施约定

- 图片：完整工作台参考为 yuncheng-concept.png；生产山湖图使用用户配置的 sevnx-imagegen、gpt-image-2.5 与 IMAGE_API_KEY 生成，页面不使用聊天模型生成图片。
- 令牌：背景 #F4F8FD，面板 #FFFFFF，主色 #3375D6，深蓝 #243B55，正文 #4D6682，辅助 #6B8098，边框 #DCE7F4；8～12px 控件/面板圆角。
- 参考布局：白色顶栏、浅蓝侧栏、左侧规划表单、右侧山湖图片与纵向城市建议。标题29px，正文/控件12～14px，右侧标题21px；品牌云朵图标与字标横向排列。
- 适配说明：保留工作台、快速规划、社区三个现有入口与保存要求、澄清、资料等业务控件，因此左侧表单比概念更长；右侧城市建议沿用现有图标，不为不同城市复用同一山湖照片冒充实景。生成结果沿用现有可编辑住宿、预算、每日地图和逐景点布局，统一视觉。

- 社区说明文案改为面向旅客的榜单与规划指引，移除页面里的数据库、端口与编程语言实现说明；保留接口、排序和点赞逻辑。
- 行程摘要采用容器宽度响应式：窄预览栏中住宿与天气两栏、预算占满一行，手机端单栏，避免按整屏宽度误判。
