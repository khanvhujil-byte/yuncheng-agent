# 云程项目介绍与教学文档

## 目标与交付

重写 README，让读者快速了解功能、架构、特点与部署方式；新增分章节的《项目教学》，参考 Hello Agents 的递进教学组织，结合本项目源码安排讲解和练习；附三张左右当前页面的样例截图。

## 范围

仅修改文档和文档图片，不修改业务代码，不删除独立历史资料。两份面向读者的文档不含历史实测、局限、踩坑记录、内部验收和面试包装。不复制参考项目文案，不宣称未实现的功能，不展示真实凭据和个人数据。价格沿用系统的参考或估算语义。

## 成功标准

README 首屏讲清用途；截图清晰；本地启动、API 配置和 Docker 部署步骤与代码一致。教程按章节提供目标、源码入口、执行过程和练习。文件链接可跳转，图片不含私人信息；完成后提交并同步公开仓库。

## 计划

核对代码与参考文档 → 截取页面 → 编写介绍与教程 → 检查链接、命令和图片 → Git 提交与推送。
